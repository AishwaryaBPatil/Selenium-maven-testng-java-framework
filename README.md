## 📌 Project Description
This project is an automation framework built using Selenium, TestNG, and Maven.
Practice Site - https://xqa.io/practice

## 🛠️ Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven

## 📁 Project Structure
src/
 ├── main/java
 ├── test/java
 └── util/

## ▶️ How to Run
1. Clone the repository
2. Open in IDE (Eclipse/IntelliJ)
3. Run testng.xml file
